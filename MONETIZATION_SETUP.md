## IMPORTANT: Website domain
Google AdSense initial signup does not accept a URL containing a path (`github.io/Grade-1-5-Scholarship/`). Google normally requires a standard registrable domain or accepted hosting partner URL. The current GitHub Pages project is free and may not be directly usable as an independent AdSense website entry. A custom domain mapped to GitHub Pages, or an approved host-partner arrangement, may be necessary. Do NOT submit `github.io` as if you owned that parent domain. No domain purchase was authorized; do not incur costs.

## Owner-only steps (not automatable from a GitHub build)
1. If eligible, create/sign in to the owner's genuine AdSense account: https://adsense.google.com/start/
2. Provide the requested legal name, address, identity and tax/payment details privately **inside Google**, never in GitHub files or ChatGPT messages.
3. In AdSense Sites, check if the production domain is accepted. If not, arrange a domain you own and configure GitHub Pages custom domain + DNS before applying. Do not buy anything without the owner's decision.
4. Confirm site ownership in AdSense/Search Console; request a review. Content must be original and provide substantial user value.
5. Configure child-directed content protections and privacy messaging with a legal/compliance review **before** enabling any ads. No personalized targeting or behavioral profiling of children.
6. After AdSense provides a genuine Publisher ID (format `pub-1234567890123456`), add its value to GitHub repository **Actions -> Variables -> ADSENSE_PUBLISHER_ID**. Next Pages deployment writes `ads.txt` under the **project path** (but note AdSense typically checks `/ads.txt` at the registered domain root, not a `/project/` subpath). To meet domain-root ads.txt requirements, a properly configured custom domain/site root is needed.
7. Only after website review says Ready and protections are configured, a **separately reviewed** change may enable compliant ad code. This repository deliberately does not auto-enable ads.
8. Payments: Sri Lanka AdSense supports wire transfers/cheques according to Google payment tables, not EFT. Verify local bank capabilities and account eligibility within Google.
9. Do not share password, bank account number, NIC, AdSense verification PIN or access token in this repository.
