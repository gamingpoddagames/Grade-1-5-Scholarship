# Blogger advertising setup (transparent, parent-friendly)

Facebook posts should keep the actual website destination: https://punchinanamaga.blogspot.com/

## What this project provides
- Reviewed Sinhala Facebook promotional captions; one Blogger link per post, no GitHub Pages link.
- `school/blogger_sponsored_entry.html`: optional **transparent** Blogger page snippet containing a clearly labeled advertising area and an independent "Continue to lessons" link.
- This is a **template only**, not a published advertisement. An approved publisher-specific Adsterra script and Blogger account edit access are required to go live.

## Setup in Blogger
1. Register the blog domain in Adsterra's publisher Websites area and wait for approval.
2. Select a non-intrusive approved ad format (e.g., Native Banner or Banner) and obtain the **actual generated code**.
3. In Blogger, go to Pages > New page > HTML view and paste `blogger_sponsored_entry.html`.
4. Replace the placeholder advertising area with the ad code exactly as issued for the verified domain. Avoid auto-redirecting visitors, forced clicks, pop-unders, misleading destination links, and ad scripts from unverified sources.
5. Preview on mobile, verify the destination button opens the Blogger home page even if ads are blocked, and publish the page.
6. If you deliberately want Facebook to link to the page, disclose it as a "sponsored welcome page" in the caption. Do not silently substitute a different destination.

**Recommended**: Place Adsterra banner/native ads within educational Blogger pages and keep Facebook linking straight to the actual articles. This reduces unnecessary friction and avoids misleading links.

Adsterra code, a Blogger approval, and live income are **not** configured or guaranteed by this repository.
